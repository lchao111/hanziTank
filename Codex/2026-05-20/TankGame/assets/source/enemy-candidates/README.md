# Enemy Candidate Sprite Specs

These files define the requested final bitmap spritesheets for the new elite enemies.
No final generated bitmap sheets are available yet, so battlefield runtime still keeps existing SVG fallback art behind Phaser primitive VFX. Enemy Gallery / Field Guide previews now use interim project-native PNG previews and 256x192-frame interim spritesheets derived from existing in-game bitmap sheets under `assets/sprites/enemies/gallery/`.

Do not promote these enemies as final-art-complete until reviewed transparent PNG spritesheets are generated, licensed, and wired from `assets/sprites/enemies/`. The interim gallery files are only for replacing raw SVG gallery art while the final art backlog remains open.

Target style: follow `ART_STYLE_GUIDE.md` exactly: kid-friendly hand-painted 2D game art, warm war-room palette, thick readable outlines, transparent background, no gore, no horror, no neon sci-fi styling.

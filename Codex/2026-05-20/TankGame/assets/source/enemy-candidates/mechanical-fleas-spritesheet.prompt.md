# Mechanical Fleas Spritesheet Prompt

Runtime id: `mechanicalFleas`
Current fallback: `assets/enemy-scout.svg`
Status: pending final bitmap spritesheet

Create a PNG spritesheet for a tiny mechanical flea swarm elite in Hanzi Tank.
Style: child-friendly hand-painted 2D game art, warm brass/olive/rust palette, thick outlines, matte metal, playful readable silhouettes.

Subject: cluster of tiny jumping clockwork flea robots with spring legs, brass bodies, small amber eyes, and dust puffs. They are toy-like, cute, and not insect-horror.

Strict sheet standard: exactly 6 columns x 5 rows. Each cell is exactly 224 x 144 px. Total canvas size is exactly 1344 x 720 px. Use a solid pure green background, exactly `#00FF00`, across the entire sheet.

Do not include checkerboard, transparent preview background, grid lines, gutters, borders, labels, or frame numbers. Every flea robot and effect must be fully inside its own 224 x 144 cell. Keep the swarm centered inside the central 70% safe area, preserve cluster spacing across frames, use the same scale per row, and keep the same baseline/anchor within each row. No dust puff, blur, spark, flame, pop burst, explosion, or debris may cross cell boundaries. Keep the swarm readable with no tiny unreadable details.

Layout rows:
Row 1: movement/driving frames, idle tiny hops and forward bounce motion.
Row 2: normal firing/attack frames, rapid hop/chip attack with compact dust puffs.
Row 3: heavy firing/attack frames, stronger spring-loaded leap attack with contained amber impact sparks.
Row 4: damaged frames, squish-spark hit reaction contained close to the swarm.
Row 5: destroyed frames, pop-burst destruction with small flames/explosion/debris contained fully inside each cell.

Negative prompt: realistic insect, horror, gore, blood, swarm grossness, neon sci-fi, photorealistic macro, cropped bodies, inconsistent spacing, transparent background, checkerboard background, grid lines, borders, effects crossing cell edges.

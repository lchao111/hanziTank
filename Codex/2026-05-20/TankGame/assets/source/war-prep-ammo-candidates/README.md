# War Prep Ammo Candidate Specs

These specs document the desired model-native art direction for future regeneration of the ammo previews/effects. The current promoted PNGs for the five newly covered ammo items are deterministic derived assets built by `tools/generate-war-prep-ammo-spritesheets.ps1` because no image generation backend was callable from this Codex session.

Use the shared style constraints from `ART_STYLE_GUIDE.md`: warm illustrated war-room UI, parchment/brass/olive palette, thick readable outlines, matte hand-painted texture, child-friendly, no gore, no flags, no political symbols, no photorealism, no neon cyberpunk styling.

Recommended output format for each item: transparent PNG spritesheet, 4 columns x 1 row, 320x192 per frame, stable framing and padding.

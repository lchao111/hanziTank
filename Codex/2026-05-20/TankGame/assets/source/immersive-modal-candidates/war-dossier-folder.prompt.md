# War Dossier Folder

## Intended Use

War archives, campaign records, or dossier-style immersive modal opener.

## Output Target

- Source: 2048x2048 transparent PNG.
- UI export: 512x512 transparent PNG.
- Optional states: closed folder, hover glow, pressed dip, open folder with documents visible.

## Prompt

Use case: stylized-concept
Asset type: game-ready 2D UI icon for a children's Chinese-learning tank game
Primary request: Create a polished war dossier folder for TankGame, a sturdy parchment-and-brass archive folder that looks like it belongs in an illustrated command room UI.
Scene/backdrop: transparent background with generous padding, no floor plane, no cast shadow outside the icon.
Subject: a khaki dossier folder with reinforced brass corners, rivets, a blank label plate, a clipped parchment map sheet, safe abstract target-grid marks, red string tie, and a few tidy paper tabs. It should suggest organized mission records, not real-world politics.
Style/medium: stylized 2D hand-painted game asset, warm war-room UI, thick readable outline, matte surface texture, kid-friendly.
Composition/framing: square icon, three-quarter top view, folder tilted slightly counterclockwise, documents peeking out but not cluttered, main silhouette readable at small size.
Lighting/mood: warm desk-lamp amber highlights, soft shadow within the asset only.
Color palette: parchment tan, muted khaki, brass, olive tabs, dark brown outline, restrained red string accent.
Materials/textures: paper fiber, worn folder edge, brushed brass, tiny dust scuffs where they improve realism without clutter.
Text: no legible text; keep label plate blank for app-rendered labels.
Constraints: no flags, no propaganda, no real-world badges, no weapons displayed as the focal point, no gore.
Avoid: photorealistic paperwork, modern office folder, neon colors, purple gradient, glossy 3D, tiny unreadable text, cluttered documents, cropped corners.

## Acceptance Checks

- Reads as an archive/dossier folder before UI text is added.
- Blank label plate is clean.
- Documents and map marks remain abstract and non-political.
- Distinct from the codex book and supply crate silhouettes.

# Enemy Field Guide Book

## Intended Use

Enemy Gallery / field guide immersive modal opener. Use as a high-polish square UI icon or as the source for hover/open button states.

## Output Target

- Source: 2048x2048 transparent PNG.
- UI export: 512x512 transparent PNG.
- Optional states: closed, hover glow, pressed dip, slightly open field-guide reveal.

## Prompt

Use case: stylized-concept
Asset type: game-ready 2D UI icon for a children's Chinese-learning tank game
Primary request: Create an enemy field guide book for TankGame, a polished illustrated field manual that feels like a warm war-room UI object rather than a flat placeholder.
Scene/backdrop: transparent background with generous padding, no floor plane, no cast shadow outside the icon.
Subject: a sturdy olive canvas field-guide book with parchment page edges, brass corner protectors, rivets, a small blank brass title plate, paper tabs, and subtle enemy silhouette page markers. The cover should suggest "field guide" through scout-map tabs and profile cards, not through readable text.
Style/medium: stylized 2D hand-painted game asset, chunky readable shapes, thick dark brown outline, matte painterly texture, slight Phaser-game feeling.
Composition/framing: square icon, three-quarter top view, book angled slightly clockwise, cover fully visible, silhouette clear at 64px, enough padding for downscaling.
Lighting/mood: warm amber war-room light, soft grounded inner shadow only, friendly and readable.
Color palette: olive green cover, tan parchment pages, muted brass hardware, dark brown outlines, small amber highlights, limited desaturated red tabs only if needed.
Materials/textures: canvas grain, worn paper edges, brushed brass corners, subtle dust scratches, no glossy finish.
Text: no legible text; leave the title plate blank for app-rendered labels.
Constraints: child-friendly, no gore, no real-world insignia, no national flags, no skulls, no photorealistic military imagery.
Avoid: photorealism, realistic war photo, horror, blood, propaganda, political symbols, neon colors, purple gradients, glossy 3D, tiny unreadable text, clutter, cropped subject, blurry icon.

## Acceptance Checks

- Reads as a field guide book before reading any UI label.
- Blank title plate remains clean and usable.
- Thick outline and major shapes stay readable at 64px.
- No real-world political or military markings.

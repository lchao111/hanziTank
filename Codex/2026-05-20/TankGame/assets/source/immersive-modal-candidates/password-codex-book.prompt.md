# Password Codex Book

## Intended Use

Password / codex / mastery records modal opener. This should replace or upgrade the existing codex-book source while preserving the current high-value animated-button direction.

## Output Target

- Preferred source: 2048x2048 transparent PNG with two side-by-side halves: closed book on the left, open book on the right.
- Existing conversion target: 6x1 spritesheet, 512x512 frames, compatible with the current codex button state pattern.
- If side-by-side source is not possible, generate closed and open transparent PNGs separately at 2048x2048 each.

## Prompt

Use case: stylized-concept
Asset type: game-ready 2D UI source art for an animated codex/password-book button
Primary request: Create a polished password codex book for TankGame, shown as two matching states in one square source image: closed codex on the left half, open codex on the right half.
Scene/backdrop: transparent background or perfectly flat removable chroma-key background if transparency is unavailable. Keep both states isolated with generous padding and no floor plane.
Subject: an old tactical password book with parchment pages, olive leather or canvas cover, brass locking clasp, rounded brass corners, red cloth bookmark, and subtle Hanzi-learning practice-sheet motifs. The open state should reveal blank parchment pages, cipher-card pockets, small brass index tabs, and a warm amber glow from the page center.
Style/medium: stylized 2D hand-painted game asset matching a warm parchment and brass war-room UI; thick readable dark-brown outline; matte textures; friendly educational tone.
Composition/framing: left half closed state, right half open state; consistent camera angle, scale, lighting, and center alignment; both states readable in 512x512 frames after cropping.
Lighting/mood: warm amber highlights, soft inner glow on the open pages, no dramatic horror lighting.
Color palette: tan parchment, olive green cover, muted brass, dark brown outlines, soft amber glow, one restrained red bookmark accent.
Materials/textures: worn paper grain, leather/canvas texture, brushed brass, subtle page edges, no glossy plastic.
Text: no legible text; use only abstract page lines or blank panels so generated text artifacts do not appear.
Constraints: child-friendly, no flags, no political insignia, no skulls, no tiny labels, no cropped clasp or bookmark.
Avoid: photorealism, gritty war photo, gore, blood, horror, neon cyberpunk, purple gradient, glossy 3D, unreadable generated text, cluttered page detail, inconsistent closed/open framing.

## Acceptance Checks

- Closed and open states appear to be the same book.
- Open pages have clean blank areas for app-rendered text or overlays.
- The object remains readable as a codex/password book at 64px.
- The source can be cropped into stable 512x512 button frames without jumpy animation.

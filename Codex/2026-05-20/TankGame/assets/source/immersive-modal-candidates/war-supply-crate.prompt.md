# War Supply Crate

## Intended Use

Supply reward crate modal artwork and opener icon. This should feel more premium than a plain box while preserving the current 512x512 UI role.

## Output Target

- Source: 2048x2048 transparent PNG.
- UI export: 512x512 transparent PNG.
- Optional states: closed crate, hover glow, opening lid, reward reveal.

## Prompt

Use case: stylized-concept
Asset type: game-ready 2D UI icon for supply reward modal
Primary request: Create a polished war supply crate for TankGame, a chunky reward crate that feels tactile, valuable, and child-friendly.
Scene/backdrop: transparent background with generous padding, no floor plane, no cast shadow outside the icon.
Subject: a sturdy olive-and-khaki supply crate with brass corner guards, rivets, dark metal latch, reinforced planks, subtle amber reward glow leaking between lid seams, and a few safe visible supplies such as coin tokens, armor plates, wrench, rolled map, and shell-shaped learning powerups. Keep contents tidy and readable.
Style/medium: stylized 2D hand-painted game asset, warm war-room UI, thick readable dark outline, matte painterly texture, slight game-sprite polish.
Composition/framing: square icon, front three-quarter view, lid closed or barely ajar, clear box silhouette, strong value contrast, readable at 64px.
Lighting/mood: warm amber glow from inside the crate, soft friendly reward mood, no harsh cinematic darkness.
Color palette: olive green panels, muted khaki wood, brass trim, dark brown outlines, amber glow, restrained red inventory tag if needed.
Materials/textures: painted wood grain, brushed brass, dusty corners, small scratches, no glossy plastic.
Text: no legible text; no serial numbers or labels.
Constraints: no flags, no skulls, no modern political markings, no dangerous realism, no cluttered contents spilling out.
Avoid: photorealistic military crate, generic brown box, neon loot chest, purple gradient, glossy 3D, tiny unreadable labels, cropped lid, blurry icon.

## Acceptance Checks

- Reads as a premium supply crate, not a placeholder box.
- Reward glow is warm amber and restrained.
- Contents remain child-safe and non-political.
- Icon remains distinct at 64px and 512px.

# Image Generation Work Log

## Goal

Create a durable image-generation workflow for TankGame assets: immersive modal art, VFX, spritesheets, UI buttons, backgrounds, and future polished bitmap assets. The standard is high-quality, child-friendly, license-safe, hand-painted WWII/war-room style art that matches `ART_STYLE_GUIDE.md`. Avoid placeholder-looking CSS/SVG art.

## Constraints

- Do not use unofficial token/proxy routing to bypass another service's quota or access controls.
- Local machine currently has Python 3.14, which is not a safe default runtime for most Stable Diffusion/ComfyUI Python packages.
- Prefer a self-contained image-generation manager or official/local generation backend.
- Record every generated or imported asset source, prompt, date, and license note before promotion into `assets/sprites/`.
